# Constela: instaladores

Aquí solo están los instaladores de Constela para Windows, no el código. La app busca sus actualizaciones en los Releases de este repositorio.

Descarga `Constela-Setup-<versión>.exe` del último release e instálalo: no pide permisos de administrador. Si Windows muestra "Windows protegió su PC", toca **Más información** y después **Ejecutar de todas formas**, porque el instalador todavía no está firmado.

Tus datos, como chats, memoria y cuentas, quedan en tu equipo, en `~/.constela`, y desinstalar no los borra.
