# Constela: instaladores

Acá solo están los instaladores de Constela para Windows (no el código). La app busca sus actualizaciones en los Releases de este repo.

Descargá `Constela-Setup-<versión>.exe` del último release e instalalo (no pide permisos de administrador). Si Windows muestra "Windows protegió su PC", tocá **Más información** y después **Ejecutar de todas formas**: el instalador todavía no está firmado.

Tus datos (chats, memoria, cuentas) quedan en tu PC, en `~/.constela`, y desinstalar no los borra.
